# 커밋 컨벤션

## 형식

```
<type>: <제목>

<본문(선택)>

<꼬리말(선택)>
```

- 제목은 50자 이내, 마침표 없이 작성
- 제목은 명령형으로 작성 (예: "수정함" X → "수정" O)
- 본문은 무엇을, 왜 변경했는지 설명 (어떻게는 코드로 확인 가능하므로 생략)
- 본문은 항상 `-` 불렛포인트로 작성

## Type 종류

| Type       | 설명                                        |
|------------|---------------------------------------------|
| `feat`     | 새로운 기능 추가                            |
| `fix`      | 버그 수정                                   |
| `refactor` | 기능 변경 없는 코드 구조 개선               |
| `style`    | 코드 포맷팅, 세미콜론 등 (동작 변화 없음)   |
| `docs`     | 문서 추가/수정                              |
| `test`     | 테스트 코드 추가/수정                       |
| `chore`    | 빌드 설정, 패키지 매니저 등 기타 변경       |
| `design`   | UI/UX 디자인 변경 (SwiftUI 뷰, 레이아웃 등) |
| `remove`   | 파일/코드 삭제                              |

## 예시

### feat

```
feat: 아이 기록 추가 화면 구현

- 기저귀 기록 입력 UI 추가
- 수유 기록 입력 UI 추가
- 수면 기록 입력 UI 추가
```

```
feat: 상어 성장 단계(신생아/영아/유아) 상태 표시 기능 추가
```

### fix

```
fix: 몸무게 입력 시 소수점이 반영되지 않는 오류 수정
```

```
fix: 구글 로그인 실패 시 앱이 종료되는 문제 수정

- 로그인 실패 응답을 처리하지 않아 앱이 강제 종료됨.
```

### refactor

```
refactor: MyiRApp 진입점 구조 정리
```

```
refactor: RecordColors 관련 로직을 별도 파일로 분리

- 뷰 파일에 색상 로직이 섞여 있어 재사용이 어려움.
```

### style

```
style: SwiftUI 뷰 들여쓰기 및 줄바꿈 정리
```

### docs

```
docs: 커밋 컨벤션 문서 초안 작성
```

### test

```
test: 몸무게 입력 유효성 검증 유닛 테스트 추가
```

### chore

```
chore: .gitignore에 xcuserdata, DerivedData 추가
```

### design

```
design: 홈 화면 카드 레이아웃 여백 및 배경색 조정
```

### remove

```
remove: 기본 템플릿 ContentView.swift 삭제

- Xcode 프로젝트 생성 시 기본으로 포함된 예시 코드로 실제 앱에서 필요 없음.
```

## 브랜치 규칙 (참고용)

- `tom/dev`: 개발 작업 브랜치
- 기능 단위 작업 시 `tom/feature/기능명` 형태 권장

## 기타 규칙

- 하나의 커밋에는 하나의 논리적 변경만 포함
- 커밋 메시지는 한글 또는 영어로 통일
